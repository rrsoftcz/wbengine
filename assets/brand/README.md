# WBengine brand assets

Official WBengine logo files. Use them as they are; do not redraw or recolour them.

- `svg/`: vector logos (icon, symbol, wordmark, light and dark variants).
- `png/`: raster copies of the same logos.
- `favicon/`: favicon sets in the blue (`#5723FC`) and charcoal (`#212225`) variants, sizes 16 to 512 px, with `.ico` files.

The primary icon is `svg/wbengine-03-icon-light.svg` on the logo purple. The skeleton site uses the blue favicon set.
